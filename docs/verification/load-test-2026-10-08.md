# Eight-user load check

Eight separate PHP processes began together against a freshly migrated, isolated MySQL database. Each user had 200 habits, 30 active habits, 11 schedule snapshots per habit and 900 historical approvals.

All 40 HTTP-kernel requests returned the expected status. Other owners’ habit pages returned 404. Eight upload requests created exactly eight queued check-ins, jobs and private photos. The measured batch took 3.33 seconds; p95 response latency was 1908 ms. Detailed timings/memory are in mysql-load-2026-10-08.json. Temporary test data was removed. No real user data, SMTP delivery or AI inference was involved.

The test runs authentication/session/throttling and renders views; Laravel’s test environment bypasses CSRF. It does not include a network web server, sustained traffic or GPU/mail service throughput. Timings are hardware/environment-specific and are recorded rather than treated as universal performance promises. CI runs a smaller four-user workload.
